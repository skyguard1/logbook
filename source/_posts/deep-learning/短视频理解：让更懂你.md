<p>&nbsp; &nbsp; &nbsp; &nbsp; 随着短视频的迅猛发展，用户规模在不断扩大，视频观看的时长也在日益增长。数据显示，人们在视频上花费的时间是图片的<span>2.6</span>倍，越来越多的人正在主动成为视频内容的消费者。而面对海量的视频，如何精准地理解短视频内容，对于增强用户的粘性和留存至关重要。</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 每天有大量<span>UGC</span>和<span>PGC</span>的视频上传，短视频的各业务场景，都涉及对视频内容的识别与理解。而视频内容识别与理解，则需要解决三个问题：“有什么”——视频中包含什么；“在哪里”——视频发生的场景；“做什么”——视频中主体的行为。</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 针对短视频，优图<span>X-Lab</span>团队的设计以深度学习短视频的理解算法为基础。该算法能识别出视频的主体、发生的场景及动作类标签，并且这项技术在管理端中已部署。</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 短视频内容识别技术效果如图<span>1</span>所示，该技术不仅能识别短视频关键目标，如人物、乐器、宠物等，还能识别发生的场景及舞蹈、体育运动类等标签。</p>

<p><b><span>四、</span></b><b>创新点的创新之处的具体描述（</b><b><span>innovation</span></b><b>）</b></p>
<p><span>1. </span>短视频内容识别的技术框架</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 短视频内容可按照主体、场景、动作三个维度来划分。首先要解决视频中“有什么”，即对关键帧做目标检测，识别视频里重点的人和物；其次解决“在哪里”，即识别视频中的关键场景；最后解决“做什么”，即识别视频中主体的运动行为。框架如图<span>2</span>所示。</p>

<p><span>2. </span>短视频识别算法的创新</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 视频标签和传统图像标签相比，算法的挑战很大，关键原因有四点：1) 视频是多帧序列的集合，有的标签要基于关键帧识别，有的则基于图像序列识别；2) 视频识别的目标是运动的，同一段视频的同一个目标外观变化较大；3) 视频的场景和图像相比更复杂多变；4) 多个模型处理视频数据，如何压缩网络模型前馈的时间。</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 针对这些挑战，我们在不同方面均进行了改进和创新，主要包括网络模型改进和模型压缩两方面。</p>
<p><span>a)&nbsp;</span>网络模型改进——提升精度</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 在目标检测模块，视频里的目标会运动，不同视角下的外观变化很大，同时检测的多类目标大小尺寸不一。我们基于<span>SSD</span>框架，引入微调<span>Anchors</span>的两个<span>loss</span>，微调后的<span>Anchors</span>，会有更好的初始值，再进入回归网络二次修正。和传统<span>two-stage</span>方法不一样的是，设计的<span>loss</span>是并行在网络中学习，这样兼顾效率。</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 在场景识别模块，最为突出的问题是正、负样本不平衡。同时正样本之间也存在不平衡的问题，并且场景识别也是个多标签的问题，同一帧图像可能存在多种场景标签。为平衡各个样本，我们从<span>QQ</span>空间、<span>OpenImage</span>等数据中进行补充和调整，再根据<span>bad case</span>，针对性地设计负样本，使得问题得到解决。另外，针对中人物类出现频次高、画面占比极大的特性，我们会根据检测结果先过滤掉这部分数据，再将剩余关键帧经过场景识别模型，大大减少了不必要的计算开销。</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 在动作识别模块，我们基于<span>TSN (Temporal Segment Networks)</span>模型，在<span>BN-Inception</span>的每个<span>Iception</span>模块增加单位<span>3D</span>卷积，同时引入<span>attention</span>机制，以此增强网络的时序捕捉能力。在模型训练方式上，加入带权重的梯度更新，从而缓解正负样本不平衡，在保证正样本召回的同时，提高模型的鲁棒性和精度。</p>
<p><span>b)&nbsp;</span>模型压缩——提升效率</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 在保证识别精度前提下，我们通过剪枝策略，对检测模型进行压缩。在评价<span>channel</span>重要性上，综合<span>L1</span>和<span>L2</span>多种度量，且对不同<span>Layer</span>，设置不同压缩比例：<span>VGG</span>模型整体压缩一半，<span>76</span>类检测模型<span>Map</span>牺牲<span>1%</span>。</p>
<p><span>3. </span>可扩展标签体系</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 通过对短视频数据的分析，我们按照可区分、易扩展原则，建立了针对短视频领域的标签体系<a name="_GoBack"></a>。一级标签主要包括三大类，即目标类、场景类、行为类标签。目标类标签分为：人物类、萌宠类、乐器类、美食类、卡通类、日常用品类等；场景类标签分为：游戏类、室内场景类、室外场景类、风景类等；行为类标签分为：体育运动类、舞蹈类等。二级标签共十五类。标签体系基本涵盖了短视频的各类标签，有效地满足了短视频内容识别的业务需求。</p>
<p><b>五</b><b>、创新如何产生的（创新点相关小故事）</b></p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 随着、快手等短视频产品的流行，越来越多短视频应用走进大家的日常生活，因此对于短视频理解显得格外重要。我们在同的合作中，了解到审核团队迫切地希望能提高打标签的效率和质量。同时审核团队每天又提供了大量有监督的视频数据，从而可以通过数据驱动，构建短视频理解的整套系统，解决审核团队面临的问题。</p>
<p><b>六、怎么实现的（<span>how</span>）</b></p>
<p>（<span>1</span>）利用信息熵等技术对短视频进行关键帧提取，同时过滤掉模糊及噪声较大的帧；</p>
<p>（<span>2</span>）检测模型对关键帧进行目标检测，对检测到人脸的帧，进行人脸属性识别，对检测到宠物的帧，进行细粒度宠物分类，同时根据检测结果，过滤掉场景模型的负样本；</p>
<p>（<span>3</span>）场景模型对未过滤的关键帧进行场景识别；</p>
<p>（<span>4</span>）动作识别模型对视频帧序列进行识别；</p>
<p>（<span>5</span>）综合各个模型识别的结果，以产品需要的标签形式输出。</p>
<p><b>七、产品意义和对未来的展望</b></p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 现在有大量短视频在上传，审核团队每天都会提供大量的标注，这些有监督的数据可用于训练短视频理解系统。同时系统还可以帮助审核人员进行高效地工作，在使用过程中又会得到新的反馈，从而形成闭环，这个闭环会形成正向循环，帮助系统识别更为精准。</p>
<p>&nbsp; &nbsp; &nbsp; &nbsp; 随着视频内容的逐渐盛行，如何从视频中获取有价值的内容意义重大。这不仅可以推动审核端更加智能，还可以提升个性化推荐的准确度。我们从审核的短视频入手，提出了基于深度学习的短视频理解技术，不仅可以解决视频分类和标签业务上的问题，还可以延伸到视频内容的理解与挖掘上，更好地为视频内容的理解与挖掘提供基础性的技术能力。</p>
