<div>
<p style="text-indent:21pt;"><span style="font-family:&#39;Times New Roman&#39;, serif;">Learning to Rank</span>（以下简称<span style="font-family:&#39;Times New Roman&#39;, serif;">LTR</span>）是搜索排序中经典的机器学习算法。</p>
<h2><b><span>LTR</span></b><b>训练数据获取</b></h2>
<p><span style="font-family:&#39;Times New Roman&#39;, serif;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; LTR</span>数据获取的方式主要有两种：人工标注和日志文件挖掘。</p>
<p><span style="font-family:&#39;Times New Roman&#39;, serif;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>人工标注：随机抽取<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>，并对返回的结果按照相关性进行分档标注，一般会分为<span style="font-family:&#39;Times New Roman&#39;, serif;">5</span>挡左右<span style="font-family:&#39;Times New Roman&#39;, serif;">(perfect</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">excellent</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">good</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">fail</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">bad)</span>。这种方式标注的<span style="font-family:&#39;Times New Roman&#39;, serif;">label</span>是较为准确的，但是费时费力。</p>
<p><span style="font-family:&#39;Times New Roman&#39;, serif;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>日志挖掘：搜索引擎有大量的用户行为日志可供挖掘，可以通过一定的规则来获取训练数据标签，最常见的规则就是点击与否。这种方式获取数据较为容易，但是人工拍规则会引入噪声导致<span style="font-family:&#39;Times New Roman&#39;, serif;">label</span>不准确。</p>
<p><span style="font-family:&#39;Times New Roman&#39;, serif;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>两种方式对<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>的抽取都需要保证随机，既要保证有热门<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>也要有长尾<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>。由于热门<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>的点击行为较丰富，容易构造数据，因此如果从日志挖掘的话，一定要兼顾长尾<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>数据。<span style="font-family:&#39;Times New Roman&#39;, serif;">LTR</span>模型主要解决的是相关性的排序，因此模型中大多是<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>和文档的相关性系列特征，这些特征是与点击无关的，这和<span style="font-family:&#39;Times New Roman&#39;, serif;">CTR</span>模型不同，没有<span style="font-family:&#39;Times New Roman&#39;, serif;">ID</span>特征用来做记忆，所以<span style="font-family:&#39;Times New Roman&#39;, serif;">LTR</span>模型作用在于泛化，能够优化长尾<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>的排序效果。</p>
<h2><b><span>LTR</span></b><b>算法类型</b></h2>
<p><span style="font-family:&#39;Times New Roman&#39;, serif;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; LTR</span>算法主要包括三种类别：<span style="font-family:&#39;Times New Roman&#39;, serif;">PointWise</span>，<span style="font-family:&#39;Times New Roman&#39;, serif;">PairWise</span>，<span style="font-family:&#39;Times New Roman&#39;, serif;">ListWise</span>。</p>
<p style="margin-left:18pt;text-indent:-18pt;"><b><span style="font-family:&#39;Times New Roman&#39;, serif;">1.<span style="font:7pt &#39;Times New Roman&#39;;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></b><b><span style="font-family:&#39;Times New Roman&#39;, serif;">PointWise</span></b></p>
<p style="text-indent:18pt;"><span style="font-family:&#39;Times New Roman&#39;, serif;">PointWise</span>方法只考虑给定<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>下，单个文档的绝对相关程度。这种方法将排序问题直接转化成了经典的分类或者回归问题，不考虑到其他文档和<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>的相关度，看重的是对象的绝对准确性，然而排序问题更看重对象的相对准确性。</p>
<p style="margin-left:18pt;text-indent:-18pt;"><b><span style="font-family:&#39;Times New Roman&#39;, serif;">2.<span style="font:7pt &#39;Times New Roman&#39;;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></b><b><span style="font-family:&#39;Times New Roman&#39;, serif;">PairWise</span></b></p>
<p style="text-indent:18pt;"><span style="font-family:&#39;Times New Roman&#39;, serif;">PairWise</span>方法是考虑给定<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>下，两个文档之间的相对相关度，也即将任意两个相关性不同的文档构造出<span style="font-family:&#39;Times New Roman&#39;, serif;">pair</span>对，学习出偏序关系。这种方法相比于<span style="font-family:&#39;Times New Roman&#39;, serif;">pointwise</span>方法有一定改进，但是和真正衡量排序效果的一些指标可能存在很大差异。</p>
<p style="margin-left:18pt;text-indent:-18pt;"><b><span style="font-family:&#39;Times New Roman&#39;, serif;">3.<span style="font:7pt &#39;Times New Roman&#39;;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></span></b><b><span style="font-family:&#39;Times New Roman&#39;, serif;">ListWise</span></b></p>
<p style="text-indent:18pt;"><span style="font-family:&#39;Times New Roman&#39;, serif;">ListWise</span>方法直接考虑给定<span style="font-family:&#39;Times New Roman&#39;, serif;">query</span>下优化文档集合的整体序列，较好的克服了上面两种方法的缺陷。</p>
<p style="text-indent:18pt;">几种经典的<span style="font-family:&#39;Times New Roman&#39;, serif;">LTR</span>算法包括：<span style="font-family:&#39;Times New Roman&#39;, serif;">RankSVM</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">GBRank</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">IRSVM</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">RankNet</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaRank</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">AdaRank</span>、<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaMART</span>。其中<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaMART</span>是性能较好的<span style="font-family:&#39;Times New Roman&#39;, serif;">listwise</span>类型的<span style="font-family:&#39;Times New Roman&#39;, serif;">LTR</span>算法，它基于<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaRank</span>和<span style="font-family:&#39;Times New Roman&#39;, serif;">MART</span>算法，而<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaRank</span>又是基于<span style="font-family:&#39;Times New Roman&#39;, serif;">RankNet</span>改进的，所以介绍<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaMART</span>之前先了解下该算法如何从<span style="font-family:&#39;Times New Roman&#39;, serif;">RankNet</span>和<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaRank</span>演进而来。</p>

<p style="text-indent:21pt;">引入<span style="font-size: 10.5pt; font-family: Calibri, &quot;sans-serif&quot;; position: relative;"></span>后，参数更新的方式变成了计算每个文档的<span style="font-size: 10.5pt; font-family: Calibri, &quot;sans-serif&quot;; position: relative;"></span>值并累计，一次更新完，而传统的<span style="font-family:&#39;Times New Roman&#39;, serif;">SGD</span>方法是每计算一个<span style="font-family:&#39;Times New Roman&#39;, serif;">pair</span>对的梯度就更新一次参数。</p>
<p style="text-indent:21pt;">至此<span style="font-family:&#39;Times New Roman&#39;, serif;">RankNet</span>介绍完了，它可以理解为一个排序方法的框架，定义了偏序学习的方法，告诉我们如何绕开<span style="font-family:&#39;Times New Roman&#39;, serif;">NDCG</span>等无法求导的评价指标得到一个可用的梯度，梯度反映了某条结果需要调序的强弱和方向，但是它不关心具体的模型是什么，即<span style="font-size: 10.5pt; font-family: Calibri, &quot;sans-serif&quot;; position: relative;"></span>可以自行定义。</p>
<h2><b><span>LambdaRank</span></b></h2>
<p><span style="font-family:&#39;Times New Roman&#39;, serif;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span>不难发现<span style="font-family:&#39;Times New Roman&#39;, serif;">RankNet</span>实质是在优化<span style="font-family:&#39;Times New Roman&#39;, serif;">pair</span>对的<span style="font-family:&#39;Times New Roman&#39;, serif;">error</span>数量，使其尽可能减少，但对于<span style="font-family:&#39;Times New Roman&#39;, serif;">NDCG</span>这样的评价指标来说，<span style="font-family:&#39;Times New Roman&#39;, serif;">error</span>数量减少并不一定是最优的优化方向。</p>

<h2><b><span>LambdaMART<a name="_GoBack"></a></span></b></h2>
<p><span style="font-family:&#39;Times New Roman&#39;, serif;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; LambdaMART</span>顾名思义是将<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaRank</span>和<span style="font-family:&#39;Times New Roman&#39;, serif;">MART</span>结合在一起，我们知道<span style="font-family:&#39;Times New Roman&#39;, serif;">MART</span>是一个框架，定义了模型，但是缺少损失函数，缺少梯度，只要损失函数可导（<span style="font-family:&#39;Times New Roman&#39;, serif;">XGBOOST</span>中要求一二阶可导）；而<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaRank</span>也是一个框架，定义了损失函数，定义了梯度，但缺少模型；二者正好完美互补，结合在一起便是<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaMART</span>。下图是<span style="font-family:&#39;Times New Roman&#39;, serif;">LambdaMART</span>算法流程：</p>
