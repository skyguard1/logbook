<h2><a name="_Toc3213"></a><a name="_Toc28777"></a><a name="_Toc12206"></a><a name="_Toc1642"></a><a name="_Toc12327"></a><span lang="EN-US">4</span><span style="font-family: 黑体;">、系统实现</span><span lang="EN-US">&nbsp; </span></h2>
<h2><b><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; &nbsp; 4.1 </span></b><b><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">整体任务流程</span></b></h2>
<p style="text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12pt; line-height: 150%; font-family: &quot;Helvetica Neue&quot;; color: rgb(68, 68, 68);">&nbsp; &nbsp;&nbsp;</span></p>
<p style="line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;</span></p>
<p style="line-height: 150%;"><b><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; &nbsp; 4.2 </span></b><b><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">重点环节说明</span></b></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; a、</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">用户输入可以是任意待分析的用户包，例如某部剧的观看用户，或则某个频道的观看用户，甚至大盘用户；</span></p>
<p style="margin-left: 42.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;</span></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; b、</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">特征区分度评估</span></p>
<p style="margin-left: 42.0pt; text-indent: 21.0pt; line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; 不是所有的特征都是有效特征，只有能区分用户行为的有效特征才有用，例如性别、年龄、地域、是否</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">VIP</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">等特征对用户的行为影响程度不同，需要定量评估。</span></p>
<p style="margin-left: 42.0pt; text-indent: 21.0pt; line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; 评估的思路：根据信息论中熵和信息增益的原理，引入一个特征对系统影响越大，说明这个特征越有用，我们用某一个特征把用户分为两个群体，然后计算这两个群体的兴趣向量余弦距离作为兴趣差异度，兴趣差异度越大说明这个特征越有区分度，反之亦然。</span></p>
<p style="margin-left: 42.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;</span></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; c、</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">特征相关度</span></p>
<p style="margin-left: 42.0pt; text-indent: 21.0pt; line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; 从</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">k-means</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">的算法原理可以推算出当某些特征高度相关时</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">(</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">例如会员和活跃天数</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">)</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">，会导致这部分特征对分群的结果影响变大，偏离实际情况。</span></p>
<p style="margin-left: 42.0pt; text-indent: 21.0pt; line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; 我们定量分析了所有特征的两两相关度，如果两个特征相关度大于</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">0.5</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">，只采用覆盖度最高的一个特征。例如：是否</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">VIP</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">、活跃天数具有较高的相关性，去掉</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">VIP</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">特征。</span><span lang="EN-US" style="font-size: 12pt; line-height: 150%; font-family: &quot;Helvetica Neue&quot;; color: rgb(68, 68, 68);">&nbsp; &nbsp; &nbsp;</span></p>
<p style="margin-left: 42.0pt; text-indent: 21.0pt; line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; 取值范围：</span></p>
<p style="margin-left: 63.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;0.0-0.1 </span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">无相关性</span></p>
<p style="margin-left: 63.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;0.1-0.3 </span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">弱相关性</span></p>
<p style="margin-left: 63.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;0.3-0.5 </span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">中相关性</span></p>
<p style="margin-left: 63.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;0.5-1.0 </span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">强相关性</span></p>
<p style="margin-left: 42.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;</span></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; d、</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">特征筛选</span></p>
<p style="margin-left: 63.0pt; line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; 经过前面的多个角度分析，只保留覆盖度高、有区分度、且相互独立的特征作为分群的依据。</span></p>
<p style="margin-left: 63.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;</span></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; e、</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">群体分析</span></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; &nbsp; 分群完成后，分析得到的各个群体人口属性、与大盘用户相比的特殊兴趣偏好。</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp; </span></p>
<p style="line-height: 150%;"><b><span lang="EN-US" style="font-size: 15.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp;</span></b></p>
<h2><a name="_Toc20241"></a><a name="_Toc6919"></a><a name="_Toc17119"></a><a name="_Toc6225"></a><a name="_Toc19099"></a><span lang="EN-US">5</span><span style="font-family: 黑体;">、分群结果举例</span></h2>
<p style="text-indent: 21.0pt; line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; 本次实验我们通过特征分析，最终采用了年龄</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">/</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">性别</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">/</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">城市等级</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">/</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">学历</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">/</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">月活天数这</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">5</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">个维度的特征，当然特征也可以根据场景需要调整。</span></p>
<p style="text-indent: 21.0pt; line-height: 150%;"><b><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; 5.1 </span></b><b><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">电视剧频道</span></b><b><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">vs</span></b><b><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">综艺频道</span></b></p>
<p style="line-height: 150%;"><span lang="EN-US" style="">&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;&nbsp;&nbsp;</span></p>
<p style="line-height: 150%;"><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; &nbsp; &nbsp; 我们使用算法自动发现电视剧和综艺频道的典型群体，通过不断调试发现群体个数在</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">15</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">个左右具有较好的人工可读性和群体区分度。</span></p>
<p style="text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12pt; line-height: 150%; font-family: &quot;Helvetica Neue&quot;; color: rgb(68, 68, 68);">&nbsp; &nbsp;&nbsp;</span></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span style="font-size: 12pt;"><strong><span style="line-height: 150%; font-family: 宋体; color: #444444;">&nbsp; 结论：</span></strong></span></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; &nbsp; A</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">、电视剧和综艺频道的典型用户群体大部分相近，唯一的区别是综艺频道用户多了一群高中女学生</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">(</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">估计没有时间追电视剧</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">)</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">；</span></p>
<p style="margin-left: 21.0pt; text-indent: 21.0pt; line-height: 150%;"><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">&nbsp; &nbsp; B</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">、电视剧和综艺用户群体在比例分布上有较大差异。例如大城市</span><span lang="EN-US" style="font-size: 12.0pt; line-height: 150%; font-family: &#39;Helvetica Neue&#39;; color: #444444;">21</span><span style="font-size: 12.0pt; line-height: 150%; font-family: 宋体; color: #444444;">岁左右的男青年明显喜欢综艺超过看电视剧。</span></p>
