<h2>1. 问题背景</h2>
<p>视频发现页的产品形态是单列沉浸式短视频信息流，用户进入页面后会在每一屏消费一个视频，通过向下滑动消费后续的视频。为了降低 qps，采用了分刷次下发视频的机制，即客户端每触发一次请求，实际会下发多个视频组成 “一刷”，当用户播放完这一刷视频时才触发下一次请求，用户连续消费多个刷次直到退出，整个过程称为一个 session。为了降低卡顿感，也存在一些预请求机制，如设置一刷剩余视频个数阈值，当剩余视频不足 N 个时预请求下一刷。</p>
<p>一刷下发的视频中包含内容视频 (recommends) 与广告视频 (ads)，分别由视频推荐引擎与商业化广告引擎生成，通过混排服务合并为一个 rec-ad list。</p>
</div>
</div>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/eb1ff8baf86b28881e80.png"/></p>
<div>
<div>
<p>广告在一刷内的相对位置称为槽位 (slot)，在保障用户体验的前提下，决策在哪些槽位插入广告使得收入最大化，就是广告混排机制要解决的问题。在产品设计之初，采用的是静态混排策略：一个 session 内的第一条广告插入第 3 位，之后的所有广告都与前一个广告间隔 5 个内容，简称 “首楼 3 间隔 5”（首楼指一个 session 内的第一条广告）。后续为了进一步提升广告收益，同时兼顾用户体验，开启了广告混排模型化的工作。</p>
<div>
<div>
<h2>2. 业界方案: 抖音 DEAR 混排模型</h2>
<p>这里主要介绍抖音的 DEAR 混排模型方案。在 DEAR 模型的设定中，要解决的混排问题是：一次请求给定 5 个内容视频，使用模型决策是否插入广告，如果要插入广告，则从 5 个候选广告中选出 1 个广告，决策要插入的槽位，即包含：是否插入广告、插入哪个广告、广告插在哪里这三个子问题。</p>
<div>
<div>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/72340b48a36be852e2db.png"/></p>
<div>
<div>
<p>为了解决这个混排问题，DEAR 模型设计了一个维度为 [ad num, rec num + 2] 的动作空间，每个动作 (action) 代表一个广告混排策略，即不下发广告 or 将广告 i 插入槽位 j（这里动作空间第二维度为 rec num + 2 的原因是：当内容视频个数为 rec num 时，广告槽位有 rec num + 1 个，此外不插入广告也是一个 action，因此是 rec num + 2）。如下图所示，5 个候选集广告分别对应 7 个 action，最终共有 35 个 action：</p>
</div>
</div>
<div>
<div>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/8cd3ccb635a50b05bb4f.png"/></p>
<div>
<div>
<p>其解法思路就是：训练一个模型，能够预估每个动作 (编号 1~35 的每个混排策略) 的收益，线上每次请求选取预估收益最大的动作作为最终的混排策略。DEAR 模型中，定义一刷的 reward 为：</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/d5282df8a4d918edb1a6.png"/></p>
<p>其中 α∈[0, 1]，用于按照一定比例线性融合两个子奖赏。</p>
<p>(1) r^ad = ad cost，为本刷广告收入；</p>
<p>(2) r^exp = 1 or -1，为用户体验奖赏，当按照某个 action 下发 rec-ad list 后，用户没有退出并继续浏览下一刷时: r^exp=1，当用户在本刷退出时: r^exp=-1</p>
<p>样本的构建方法如下：</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/a8a6ac3a88db3425bb0d.png"/></p>
<p>网络结构、训练方法及预测方法如下图所示：</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/1f904f54befde811aeb0.png"/></p>
<p>(1) 模型输入：用户特征与上下文特征（用 state feature 表示），广告特征（用 action feature 表示），由于候选广告有 5 个，因此需要将 state feature 广播后与 action feature 拼接作为模型输入；</p>
<p>(2) 模型输出：每个 action 的预估收益 Q，线上选择 Q 值最大的 action 作为最终的广告混排策略。</p>

<h2>3. 视频发现页基线方案</h2>
<p>视频发现页的基线混排模型，对比 DEAR 模型的差异点在于：</p>
<p>(1) 动作空间不同</p>
<p>抖音 DEAR 模型一刷只插入最多 1 个广告，而发现页允许在一刷内插入多个广告。因此发现页基线模型的动作空间设计，枚举了所有的广告位组合方式，以 &lt;首楼, 间隔&gt; 数对的形式给出：</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/da7e0494515e2569463d.png"/></p>
<p>(2) 网络结构不同</p>
<p>视频发现页基线模型采用的网络结构与线上预估流程如下图所示：</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/270a39e93d5e509ff3d9.png"/></p>
<p>与 DEAR 模型的网络结构差异点在于：</p>
<ul><li>
<p>模型输入不同：发现页基线模型中没有 action feature，这是因为受限于原有的工程架构，混排模型位于广告召回之前，因此无法获取广告相关的特征。</p>
</li>
</ul><ul><li>
<p>模型输出不同：在 DEAR 模型中，输出是一个单一的 Q 值矩阵，虽然 reward 设计为是否下刷 (有下刷则为 +1，无下刷则为 -1) 与广告收入的线性融合，但线上并没有显式地预测这两个值，更没有显式地对这两个预测值进行加权求和操作，而是通过离线训练的方式使得网络具有这样的预测能力，线上直接通过训练好的模型输出最终的 Q 值矩阵。</p>
</li>
</ul><p>相比之下，发现页基线模型的输出不是一个单一的 Q 值矩阵，而是采用了多任务结构，预测目标包括 continue rate (下刷率) 与 predict ad cost (本刷广告收入)，分别与 DEAR 模型中的两个 sub-reward 对应。线上使用方法为：将两个 sub-reward 线性融合后，取值最大的 action 作为最终的广告混排策略。如 “首 4 隔 4”，那么混排服务就会将这个决策反馈给上游，请求广告服务 () 获取相应数量的广告，供后续服务排版下发。</p>
<p>之所以分成两个 sub-reward 在线上做融合，是为了便于快速实验不同的融合权重对线上效果的影响。</p>
<ul><li>
<p>训练方式不同：DEAR 模型为了预估长期收益，采用了强化学习的训练方式。发现页基线模型则采用了多任务监督学习的训练方式，只预估短期收益。之所以这样设计，是为了简化问题，渐进式地取得业务收益，降低新技术的落地难度。</p>
</li>
</ul><p>样本按照刷次进行组织，下刷率的 label 为二分类 0/1 标签，当 30 分钟内有下一刷且下一刷的视频消费个数 &gt;= 1 时标记为正样本；本刷广告收入为回归目标，使用 ad cost 之和作为 target。模型输入的 state feature 包含用户与上下文特征，如过去 7/30 天的内容播放次数、广告点击次数等。通过 MLP 网络，分别输出每个 action 对应的下刷率与预估本刷广告收入。</p>
<div>
<div>
<p>根据第 3 节的对比，可以发现以下几点优化方向，本文的工作主要介绍动作空间升级为支持可变间隔过程中的模型优化实践。</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/3bc6aff74386bd5c5d2e.png"/></p>

<h2>4. 模型优化实践</h2>
<h3>4.1 双流网络改造</h3>
<p>action 基数增大, 由原来的 38 个增加至 60 个, 模型学习难度提升。假设有三个动作 i, j, k 对应的下刷率预测值如下:</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/6104d9f71aedfb4c4bd0.png"/></p>
<p>其中 s 表示 state feature，a 表示 action feature，θ 为共享参数，α 为各个动作 head 的独有参数。则训练过程中，当动作 i 在更新 θ 与 α_i 时，α_j 和 α_k 得不到更新，从而导致训练数据少的动作学习慢。</p>
<p>借鉴 RL 中的 dueling network，将 Q 拆分为 state value function 与 action advantage function：</p>
<p>Q = V + A - mean(A)</p>
<p>优点：在训练过程中，当动作 i 更新 θ 与 α_i，其他动作对应的参数也可以得到更新，从而提升模型的学习效率与鲁棒性。</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/f1ce13c2fae3a10efb0c.png"/></p>
<p>根据 reduce 函数与 sigmoid 函数位置的差异，设计对比了以下不同版本网络结构的效果差异：</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/dca8d5af2cadcc6cc82d.png"/></p>
<p>其中 V4 版本效果最佳，离线AUC +0.011</p>
<h3>4.2 动作特征优化</h3>
<p>借鉴抖音 DEAR network，将每个动作相关的特征分别构建后，再与 state feature (广播) 拼接，送入相同的网络，对每个 action 打分。网络结构改造如下：</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/560b1852c6abefd3438c.png"/></p>
<p>优点：可以单独优化每个 action 的特征，如广告 eCPM 特征，对不同的 action 支持 mask 掉冗余的 eCPM 特征；支持添加 action 泛化特征，增强模型鲁棒性，如 action 静态属性特征、target encoding 特征等。</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/4c642f39aa2ed952bf13.png"/></p>
<p>值得注意的是，这一优化点可以与 4.1 的双流网络优化点结合，进一步提升模型的效果。</p>

<h3>4.4 线上效果</h3>
<p>线上效果：</p>
<p>(1) 以下刷率为单目标，则广告收入、广告曝光下降；</p>
<p>(2) 以本刷收入为单目标，则广告收入、广告曝光上涨；</p>
<p>(3) 两者的线性融合，可以取得介于两者之间的效果，如下图所示</p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/a49caa9c0822615acfbb.png"/></p>
<p><img alt="" loading="lazy" src="/logbook/images/algorithm/9ae926d04171c1cc9c75.png"/><img alt="" loading="lazy" src="/logbook/images/algorithm/40a6dc62cdb4646d8b94.png"/></p>
<p>为了进一步去除低价值广告提升 eCPM，实验最终版本引入了非线性策略对低价值广告进行抑制。推全收益：收入 +10.7%；人均内容 vv +1.19%；人均内容播放时长+0.32%。</p>
