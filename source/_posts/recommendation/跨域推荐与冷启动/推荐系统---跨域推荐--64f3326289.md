<p>       做推荐业务时候，有时会面临当前的业务场景数据较少，无法较好的训练推荐模型，但是在同一个APP或网站上其余的大场景的流量很大，有很多的数据，如何使用其余场景域的数据辅助当前场景进行模型训练是一个值得思考的问题。如果是NLP和CV领域，当下较成熟的方案就是fine-tune, 利用预训练好的模型微调一下，就可以使用了，这是因为以上两个任务本质上的数据很标准，大家用户的都差不多，无非是任务不同。但是在推荐领域，业务场景差异很大，特征、用户、内容都有较大差别，直接使用微调，未必能取得较好效果。下面介绍几种当前跨域推荐的一些进展，以及我们的业务上的一些探索。</p>
<h3><strong>      1、Minet</strong></h3>
<p><strong>         </strong>全称是Mixed Interest Network for Cross-Domain Click-Through Rate Prediction 是阿里的一篇文章，主要介绍在UC头条上（如下图所示），如何使用用户在自然推荐（source domain）上的行为，来提升在广告（target domain）上的点击率预估效果。</p>
<p>   先看场景数据，比较好理解，就是新闻和广告，只不过，新闻曝光量大于广告很多，用户是同一个用户，且二者曝光的顺序间隔较为接近。</p>
<p><img alt="" loading="lazy" src="/logbook/images/recommendation/02e779d4ec5ef3341154.png"/></p>
<p></p>
<p>    模型结构如下图。</p>
<p>             <img alt="" loading="lazy" src="/logbook/images/recommendation/5e0727d8823bfeb0d339.png"/></p>
<p>     建模思路是根据用户在内容上的行为和在广告上的行为，都捕获到，然后看看在内容上的行为是否对在广告上的有帮助。用户兴趣分成了三部分：1、用户的固有长期兴趣，通过用户基本属性特征表示；2、用户在内容上的短期兴趣，通过用户的内容行为序列表示；3、用户在广告上的短期兴趣，通过用户在广告上的行为序列表示。</p>
<p>       然后再输入用户对两个item的label，作为模型的label，有两个label，也就有两个loss，果然辅助loss被玩坏了。模型采用了两个层级的attention，第一个item级别的，主要是从用户的点击行为中抽取出和目标广告相关的信息，另一个是interest级别的，主要是建模不同兴趣的重要程度。</p>
<p>      特征embedding，这部分不用多讲，已经是业内的常用手段，如用户ID、用户性别，用户所在地域，用户的手机设备型号、用户点击过的自然结果ID、广告结果ID,各自id，先来一个embedding。</p>
<p>       用户长期兴趣，基础属性变embedding，然后拼接，简单粗暴。</p>
<p>       用户在内容上的短期兴趣 。抽取用户在source domain中的兴趣。用户近期点击过的每一个自然结果对应的向量用<strong>r<sub>si</sub></strong>表示。主要的做法是对这些向量进行加权求和，得到输出<strong>a<sub>s</sub></strong>:</p>

<h3> 2、DTCDR</h3>
<div>        上面的是一个辅助另一个训练，但是如果另一个也想获利怎么办，双向迁移的模型也是有的。</div>
<div></div>
<div>       <img alt="" loading="lazy" src="/logbook/images/recommendation/bb18133dfad595c7a3c9.png"/></div>
<div></div>
<div>    输入层和输出基本不变。共享层的实现细节：（1）共享层被细分为嵌入层（Embedding Layer）和合并层（Combination Layer）。在嵌入层，分别使用Doc2Vec模型来生成用户和物品的文本特征表示，以及两种评分嵌入技术来生成用户和物品的评分特征表示。在合并层，使用max-pooling策略分别合成共同用户分别来至领域A和B的文本以及评分信息。接着使用三种不同的合并策略来合成文本以及评分信息。（2）通过共享层，优化了领域A和B中共同用户的特征表示，并同两个领域分别的物品特征表示一起作为模型层的输入。在模型层，使用了全连接的MLP来学习用户和物品之间的非线性关系，并最终得到喜好预测（Score）给输出层。</div>
<div></div>
<div>以上是两种跨越推荐的模型，后面介绍我们在做跨域推荐时候基于这两种框架做的一些尝试和探索。</div>

<div><strong>3、基于无量实现跨域推荐模型</strong></div>
<div><strong>    样本构造</strong></div>
<div>    无量采用的是ksv训练数据格式，在进行跨域样本生产的时候，需要先将源域和目标域的样本进行拼接。</div>
<div>    离线拼接使用spark实现，在拼接时候需要保证左右两侧的样本数目一致，需要对目标域的样本进行上采样。</div>
<div></div>
<div><strong>   源域实时兴趣attention</strong></div>
<div><strong>   </strong>使用attention模块，提取用户在源域内的实时兴趣(消费行为序列)。</div>

<pre>class ItemAttention(object):
    def __init__(self,
                 clk_list_emb,
                 item_emb_re,
                 user_emb_re,
                 embed_dim,
                 item_attn_hidden_dim,
                 clk_n_dim,
                 name):
        super(ItemAttention, self).__init__()
        self.clk_list_emb = clk_list_emb
        self.item_emb_re = item_emb_re
        self.user_emb_re = user_emb_re
        self.embed_dim = embed_dim
        self.item_attn_hidden_dim = item_attn_hidden_dim
        self.clk_n_dim = clk_n_dim
        self.name = name

    def model_fn(self):
        # _, _, embed_dim = clk_list_emb.shape
        clk_list_emb_re = tf.reshape(self.clk_list_emb, [-1, self.embed_dim])

        cur_input = tf.concat(
            [
                clk_list_emb_re,
                self.item_emb_re,
                self.user_emb_re,
                tf.multiply(clk_list_emb_re, self.item_emb_re)
            ],
            1
        )

        # _, in_dim = cur_input.shape
        out_dim = self.item_attn_hidden_dim
        in_dim = cur_input.shape[-1].value
        cur_range = np.sqrt(6.0 / (in_dim + out_dim))
        v1 = tf.get_variable(
            name="{0}_V1".format(self.name),
            shape=[in_dim, out_dim],
            dtype=tf.float32,
            initializer=tf.random_normal_initializer(
                mean=0.0,
                stddev=cur_range,
                seed=None,
                dtype=tf.float32
            )
        )

        in_dim = self.item_attn_hidden_dim
        out_dim = 1
        cur_range = np.sqrt(6.0 / (in_dim + out_dim))
        vv1 = tf.get_variable(
            name="{0}_VV1".format(self.name),
            shape=[in_dim, out_dim],
            dtype=tf.float32,
            initializer=tf.random_normal_initializer(
                mean=0.0,
                stddev=cur_range,
                seed=None,
                dtype=tf.float32
            )
        )

        hidden = tf.nn.relu(tf.matmul(cur_input, v1))
        weight = tf.matmul(hidden, vv1)
        weight = tf.reshape(weight, [-1, self.clk_n_dim, 1])
        nlz_wgt_clk = tf.nn.softmax(weight, dim=1)
        clk_list_embed_ig = self.clk_list_emb * nlz_wgt_clk
        clk_list_embed_agg = tf.reduce_sum(clk_list_embed_ig, 1)
        return clk_list_embed_agg</pre>

<pre>class InterestAttention(object):
    def __init__(self,
                 item_emb,
                 need_attention_dict,
                 in_dim,
                 interest_attn_hidden_dim,
                 name):
        super(InterestAttention, self).__init__()

        self.item_emb = item_emb
        self.need_attention_dict = need_attention_dict  # k作为name，v为embedding向量
        self.in_dim = in_dim
        self.interest_attn_hidden_dim = interest_attn_hidden_dim
        self.name = name

    def model_fn(self):
        data_embed_z = tf.concat(
            self.item_emb + list(self.need_attention_dict.values()),
            axis=1
        )

        # _, in_dim = data_embed_z.shape
        weight_attention_list = []
        index = 0
        for name, embedding in self.need_attention_dict.items():
            # 创建对应的变量
            out_dim = self.interest_attn_hidden_dim
            cur_range_dw = np.sqrt(6.0 / (self.in_dim + out_dim))

            dw = tf.get_variable(name="{}_dw_name".format(name)
                                 , shape=[self.in_dim, out_dim]
                                 , dtype=tf.float32
                                 , initializer=tf.random_normal_initializer(
                    mean=0.0
                    , stddev=cur_range_dw
                    , seed=None
                    , dtype=tf.float32
                ))

            cur_range_da = np.sqrt(6.0 / (out_dim + 1))

            # 计算权重
            dh = tf.get_variable(
                name="{0}_{1}_dh_name".format(name, index),
                shape=[out_dim, 1],
                dtype=tf.float32,
                initializer=tf.random_normal_initializer(
                    mean=0.0,
                    stddev=cur_range_da,
                    seed=None,
                    dtype=tf.float32
                )
            )

            db = tf.get_variable(
                name="{0}_{1}_db_name".format(name, index),
                shape=[1],
                dtype=tf.float32,
                initializer=tf.constant_initializer(
                    value=1.0,
                    dtype=tf.float32
                )
            )

            hidden = tf.nn.relu(tf.matmul(data_embed_z, dw))
            weight = tf.exp(tf.matmul(hidden, dh) + db, name="weight_{0}_{1}".format(name, index))
            index = index + 1
            weight_attention_list.append(weight * embedding)

        data_embed_dg = tf.concat(self.item_emb + weight_attention_list, axis=1, name="data_embed_dg_concat")
        return data_embed_dg</pre>
